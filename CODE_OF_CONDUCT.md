# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be decent. Critique the code, not the person. Assume the other party
is acting in good faith, especially across a language barrier or a time zone.

Disagreement about technical direction is welcome and useful — this is a
security tool, and unchallenged assumptions are how holes survive. Harassment,
personal attacks, and bad-faith argument are not.

Report a problem to the maintainer at asin.adarsh@gmail.com. Reports will be
handled privately.
